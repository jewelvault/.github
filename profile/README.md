<h1 align="center">JewelVault</h1>

<p align="center">A connected toolkit for jewellery businesses.</p>

JewelVault brings together tools for jewellery inventory, sales, customer and employee workflows, and business administration.

## Our products

- [JewelVault Mobile](https://github.com/jewelvault/JewelVaultMobile) — Android app for store operations.
- [Web Console](https://github.com/jewelvault/jewelVaultConsole) — merchant and support workspace.
- [Customer Portal](https://github.com/jewelvault/JewelVaultCustomerPortal) · [Employee Portal](https://github.com/jewelvault/JewelVaultEmployeePortal) · [Admin System](https://github.com/jewelvault/JewelVaultAdminSystem)
- [Public Website](https://jewelvault.co.in/)

## Technology

Our platform includes a Django backend, a React web suite, and an Android application. The desktop app provides a Windows shell for the web console.
